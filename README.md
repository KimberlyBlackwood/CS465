Functionality
How is JSON different from JavaScript and how does JSON tie together the frontend and backend development pieces?
Difference Between JSON and JavaScript
Difference	JSON	JavaScript
What it is	 A lightweight, text-based data interchange format derived from JavaScript object syntax, but it is strictly a data format, not a programming language. 
	JavaScript is a full-fledged, general-purpose programming language containing logic, functions, variables, methods, and the ability to manipulate data in memory
Syntax	JSON is rigid: all keys and strings must use double quotes, comments are not allowed, trailing commas will break it, and it cannot store executable code or functions. 
	JavaScript objects are flexible, keys do not require quotes, and they can contain functions, undefined, dates, and methods.
Language independence	 JSON is universal and can be read, parsed, or generated by dozens of programming languages (such as Python, Java, Go, and C#),
	JavaScript objects only live inside the JavaScript runtime environment.
(Mustafa.H,2026).

By using GET, POST, PUT, and DELETE., API testing checks endpoints that validate user actions. Having a robust security is critical when building a website, it  prevents data breaches and maintain confidentiality.

HTTP Method	Description	Example Use
GET	Retrieves data from the server	Fetch user details
POST	Sends data to create a new resource	Create a new user
PUT	Updates an existing resource completely	Update full user profile
PATCH	Updates part of an existing resource	Update only email address
DELETE	Deletes a resource	Delete a user record
